## What is vibecoding?

Depending on who you ask, it is LLM assisted development where you don't read the code or LLM assisted development
where you can't read the code either, because you're not a software developer.

If you're in an environment where the outcome matters more than the process, you may find yourself letting the bot
write more and more of the code. This used to be problematic for quality reasons. Now it is problematic for skill
atrophy reasons.

## What is reverse-vibecoding?

My idea is to let the LLM do the parts of software development that I'm not good at and keep the part that I am good at,
coding.

Software development, especially for pay in large organizations is a team activity, with project managers, scrum
masters, testers, and sometimes companies remember to hire developers, too. A lot of that work outside of core software
development can also be delegated to an LLM, so let's do that and keep the coding for ourselves. This speeds up the overall
process, but not nearly as much as letting the LLM write all the code.
